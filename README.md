# knhanes_atlas

KNHANES 2007–2024 在线交互图谱。保留现有 Shiny 界面，用浏览器运行 R，无需购买 R 服务器。

**网站：** https://zjy666223.github.io/knhanes_atlas/

**仓库：** https://github.com/zjy666223/knhanes_atlas

## 打开查看

双击 `01_预览.command`，或在本地服务运行时打开：

http://127.0.0.1:8848/knhanes_atlas/

首页、研究流程图和文件下载先显示，R 交互功能在后台启动。加载完成时保持当前阅读位置；提前选择栏目，会在准备好后自动打开。交互启动时间取决于访问者的网速和电脑。

启动程序包从约 99 MiB 精简到 53 MiB（49 个包）；效应振动明细在进入模块时按表型读取。首次启动不再刷新整页，更新通过构建标识获取新版应用，同时复用浏览器中的运行环境缓存。

运行文件在后台每次下载 4 个，并保存在浏览器缓存中。更新运行环境时只清理本站旧缓存；程序包清单单独刷新，避免继续读取旧版依赖。浏览器无法保存缓存时仍可通过网络加载。

本次 GitHub Pages 实测：首页约 2.3 秒显示，首次交互约 44 秒可用，缓存后约 12 秒。加载期间可阅读研究内容或直接下载文件；结果来自本次浏览器测试，具体速度随网络和设备变化。

## 已核验

- 19 项图形输出，以及表型、暴露、分组、目录和效应振动页面。
- 下拉搜索、表格搜索/排序/翻页、三类分享链接、11 张图片预览和 PDF 下载。
- 9 组浏览器 CSV 下载与本机 R 输出逐列一致。
- 149 个表型数据分块完整保留全部模型记录，包括失败状态和分类参考组。
- 轻量首页、手机宽度、提前选择栏目、返回首页、阅读位置，以及启动失败时的重试和直接下载。

原网站文件没有修改，没有重新拟合研究模型。仅转换结果存储方式，并适配浏览器下载和路径。

## 文件位置

- `site/`：待发布的网站，约 363 MiB，包含 R 运行环境、研究结果及程序包；此大小不等于首次下载量。上一版包文件暂留供旧页面访问，启动清单只包含当前需要的包。
- `src/`：迁移后的 Shiny 源码。
- `scripts/`：转换、构建和检查脚本。
- `checks/`：核验结果、截图和下载样本；不上传 GitHub。
- `work/`：本项目构建工具、浏览器缓存和临时文件；不上传 GitHub。

所有新文件均在本文件夹内。

## GitHub Pages

仓库使用 GitHub Actions 发布。向 `main` 分支推送更新后，工作流自动发布 `site/`。发布记录可在仓库的 **Actions** 页面查看。

GitHub Pages 网址可直接供审稿人访问，不要求访问者安装 R。浏览器需支持 WebAssembly 和 Service Worker。

运行环境和 R 程序包随网站保存，访问时不从第三方仓库临时安装。构建记录见 `site/build.json`。

## 重新构建

双击 `02_构建.command`。需要本机现有 R 环境，以及同级 `04_源码网站`、`01_网站` 文件夹。日志写入 `checks/`。

`01_预览.command` 的终端在本地查看期间需保持运行。发布到 GitHub Pages 后，不依赖这台电脑在线。
